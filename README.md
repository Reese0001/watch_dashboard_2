# OpenVela Watch Dashboard

# 团队成员：颜涛 袁鹏 杜禹衡

基于 Xiaomi Vela JS 开发的多页面穿戴仪表盘，在同一个横向滑动界面中整合天气、运动三环、健康概览和指南针，并分别适配 Xiaomi Watch S4 圆形屏与 Band Pro 矩形屏。

完整需求演变、当前实现、素材、模拟器验证、已知限制和后续计划请先阅读 [PROJECT_SESSION.md](./PROJECT_SESSION.md)。该文档是继续开发时的当前事实基线。

## 功能特性

- **横向四页**: 天气、今日运动、健康概览、指南针
- **实时天气**: 定位、城市反查、Open-Meteo 实时天气和三日预报、缓存降级
- **运动三环**: 活动千卡、锻炼分钟、站立小时三层同心进度环
- **健康概览**: 心率、血氧、呼吸、腕温和 HRV 展示
- **指南针**: 方向、角度、精度状态与海拔界面
- **稳定图标**: 重要图标使用 PNG，减少设备字体差异
- **多屏适配**: 使用 Vela 媒体查询区分圆形、矩形和胶囊形屏幕
- **圆形手表**: Xiaomi Watch S4 模拟器已验证
- **矩形设备**: Xiaomi Band Pro 模拟器已验证
- **胶囊设备**: 已存在媒体查询规则，尚未完成目标设备实机验证
- **真实与演示数据分离**: 天气和传感器尽可能使用系统能力，健康数据保持演示语义
- **设备约束**: 不包含分贝功能和旋转指针
- **历史详情页**: 保留早期详情页与可行性验证页，当前主流程以四页横滑界面为准

## 项目结构

```
src/
├── app.ux                 # 应用入口
├── manifest.json          # 应用配置
├── pages/
│   ├── index/            # 天气、运动、健康、指南针四页主界面
│   │   └── index.ux
│   ├── detail/           # 数据详情页
│   └── feasibility/      # 技术可行性验证页
└── common/               # 公共资源与既有组件
```
